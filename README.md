# Core Cloud DMS Terraform Module

A Core Cloud Terraform module for AWS Database Migration Service (DMS), used to migrate databases into Core Cloud, for example from ACP RDS.

> [!NOTE]
> This module is under development. The resources, inputs and usage will be added in a follow-up release.

This module includes the following checks and scans: Terraform validate, Terraform fmt, Terraform test, TFLint, Checkov, SonarQube and semantic versioning (MAJOR.MINOR.PATCH).

## Requirements

| Name | Version |
|------|---------|
| terraform | >= 1.7.5 |
| aws | >= 6.0.0 |
